## Архитектура приложения:

Приложение состоит из трех страниц, которые выводятся через элемент Frame отдельной (главной) страницы MainWindow.xaml. На этой же странице расположены кнопки для навигации с номерами заданий. При нажатии на них создается новый экземпляр страницы, соответствующей выбранному заданию.

При наведении на поля для ввода данных появляется всплывающая подсказка. Вычисления осуществляются при нажатии на кнопку "Вычислить", очистить введенные значения можно по кномке "Очистить".

Был проведен рефакторинг кода - все математические функции были вынесены в отдельный класс Funcs.

### Вывод о тестировании
Было проведено модульное тестирование трех основных методов (Func1, Func2, Func3). Тестирование охватило проверку математических расчетов, логических ветвлений и в целом работу функций. Тесты прошли успешно, показывая правильность разработанных функций, на это повлияла точность сравнения (перегрузка метода Assert.AreEqual), рассмотрение разных логических ветвей (проверки всех условий), а так же проверка граничных условий.

### Выводы о методах объекта Assert и примеры:
            // Assert.AreEqual — проверяет равенство
            Assert.AreEqual(4, 2 + 2);

            // Assert.AreNotEqual — проверяет неравенство
            Assert.AreNotEqual(5, 2 + 2);

            // Assert.IsTrue — проверяет истинность условия
            Assert.IsTrue(10 > 5);

            // Assert.IsFalse — проверяет ложность условия
            Assert.IsFalse(3 > 10);

            // Assert.IsNull — проверяет, что объект равен null
            object obj = null;
            Assert.IsNull(obj);

            // Assert.IsNotNull — проверяет, что объект не равен null
            object obj2 = new object();
            Assert.IsNotNull(obj2);
